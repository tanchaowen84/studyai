## **MVP v1 — 以 PDF 为核心的学习计划 + PDF 聊天（中文）**

### **一句话承诺**

用户上传 PDF → 系统总结并生成 **学习计划** → 用户可以与 **PDF 聊天**。这就足够上线。番茄钟、进度条、学科文件夹后续再做。

---
### **MVP v1 必须包含（上线范围）**

#### **1) PDF 上传（v1 只做单一主题）**

- 上传 PDF（允许多份）

- PDF 列表管理：重命名 / 删除

#### **2) PDF → 结构化课程（学习计划生成）**

- 解析 PDF（文本抽取 + 基础切分）

- 生成：

    - **模块**（Module 1..N）

    - 每个模块的 **总结**

- 内容需可追溯回 PDF（至少保留 **页码范围 / 段落范围**）

#### **3) PDF 聊天（核心交互）**

- 允许用户基于 PDF 内容提问并得到回答

- 回答尽量带来源引用（页码/段落）

---

### **MVP v1 路线图（执行步骤）**

1) **基础与登录**

- 确认登录/注册可用

- 创建初始的“课程/项目”入口（v1 单主题）

2) **PDF 上传与管理**

- 上传 PDF

- 重命名 / 删除

- 存储到 S3/R2

3) **PDF 解析与切分**

- 抽取文本

- 按页/段进行基础切分

- 记录页码范围以便溯源

4) **AI 学习计划生成**

- 从内容生成模块

- 生成每个模块摘要

- 存储模块 ↔ 页码范围映射

5) **PDF Chat**

- 基于上传内容的问答

- 回答包含页码/段落引用

6) **最小 UI 与流程**

- 上传页 → 课程页 → 聊天页

- 清晰的“继续学习”流程

- 成功/失败状态提示

7) **MVP 测试与上线**

- 全流程验证：上传 → 计划 → 聊天

- 准备基础文档 / onboarding

---

### **技术方案（MVP）**

- **PDF 解析**：LangChain JS PDFLoader（或 pdf-parse）抽取文本（不做 OCR）。

- **切块策略**：RecursiveCharacterTextSplitter；保留页码/段落元数据。

- **Embeddings**：OpenRouter embeddings API（OpenAI 兼容地址）。

- **向量库**：Supabase Postgres + pgvector（启用 `vector` 扩展）。

- **检索方式**：Top‑K 语义检索 + 引用页码。

- **RAG 流程**：query → embed → 检索 chunks → 组装上下文 → LLM 回答。

- **文件存储**：PDF 文件存对象存储（S3/R2），数据库仅存元数据与 chunks。

## **Studyroom 项目化设计（讨论结论）**

### **目标**

- 每个上传的 PDF 生成一个独立的学习项目（room）
- 项目页面采用 `/studyroom/{roomId}` 结构
- `/studyroom` 作为入口/创建页，同时展示最近项目

---

### **路由结构**

- `/studyroom`：入口 + 创建 + 最近项目列表
- `/studyroom/{roomId}`：项目内阅读 + AI Chat

---

### **Room 数据结构（建议）**

- `id`：UUID（主键）
- `title`：可编辑标题（默认取文件名）
- `fileUrl`：R2 公网访问 URL
- `fileKey`：R2 对象路径（用于删除/替换/迁移）
- `pageCount`：页数（用于后续进度）
- `ownerId`：用户 ID
- `createdAt` / `updatedAt`
- `status`：active / archived（可选）

---

### **上传流程**

1. 用户在 `/studyroom` 上传 PDF
2. 上传至 R2，返回 `fileUrl` + `fileKey`
3. 创建 room 记录（写入数据库）
4. **自动跳转**至 `/studyroom/{roomId}`

---

### **关键约束**

- **一个 room 只对应一个 PDF**
- 保留 `fileKey` 用于后续删除/替换
- 允许未来扩展“多 PDF 参与 AI 对话”，但不在 MVP 做

---

### **最近项目（Studyroom 首页）**

- 列表展示最近 N 个 room（标题、更新时间、页数/进度）
- 点击进入对应 `/studyroom/{roomId}`
